## Not tested

These are untested rather than known to fail.

- Nuxt versions between 3.12.4, 3.21.11 and 4.7.0, the ones that were run. See [browser support](/guides/browser-support#compatibility).
- Safari, Edge, and Firefox versions that have the View Transitions API. See [browser support](/guides/browser-support).
- Rapid toggling in Chrome on a real GPU.
- A strict Content-Security-Policy with the standalone head script.
- Specific screen readers.
- Each effect looked at one by one in every browser.

## Not done

- Page navigation does not get a theme animation. A theme change during a navigation applies instantly.
- No per-component or per-route theme. There is one theme for the whole document.
- No built-in picker with a list or radio group. `PenumbraToggle` cycles through `themes`; build a list with `usePenumbra().setTheme`.
- Reduced motion is read when the theme changes, not watched live.
- No config option for a different effect per theme direction.

If you hit something that should work, open an issue at [github.com/jantursky/nuxt-penumbra](https://github.com/jantursky/nuxt-penumbra/issues).
