---
title: Using Astro?
description: astro-eclipse is the Astro integration that runs the same transition engine.
---

If you build with Astro, look at [astro-eclipse](https://github.com/jantursky/astro-eclipse). It is the same author's integration for Astro, and it runs the same engine, `@penumbra/core`. The effects, their names, `origin`, `direction`, `duration` and `easing` options, and `defineTransition` work the same way in both.

What differs is the integration around the engine. astro-eclipse works with Astro's `ClientRouter`, ships components for Astro, and has its own client API. nuxt-penumbra works with Nuxt, `@nuxtjs/color-mode` and Nuxt UI. The two packages do not depend on each other.

- Astro docs: [astro-eclipse-docs.vercel.app](https://astro-eclipse-docs.vercel.app)
- Astro demo: [astro-eclipse-demo.vercel.app](https://astro-eclipse-demo.vercel.app)
- Repository: [github.com/jantursky/astro-eclipse](https://github.com/jantursky/astro-eclipse)
